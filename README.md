# BANTABA — Coming Soon

A standalone, responsive launch countdown page for BANTABA.

## Features
- Fixed three-day launch countdown targeting **27 October 2026 at 12:00 UTC**.
- Clear notice that the launch target may change based on development progress.
- “Speed up launch” opens a support popup linking to SquashberryPay.
- Accessible modal controls, mobile-responsive styling, and no external framework dependencies.

## Launch target
The countdown target lives in `index.html` as `launchAt`. Update it when the team announces a new target; the displayed disclaimer intentionally makes clear that the date is not a guarantee.

## Hosting
This is a plain static site. GitHub Pages serves it from the repository root.
